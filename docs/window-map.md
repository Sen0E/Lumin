# 窗口职责与功能位置

当前版本：Lumin 0.13.1。三个业务窗口各自维护状态；设置与数据管理、即时翻译、图片识别分别组织。

## 主窗口

| 页面 | 功能 |
| --- | --- |
| 常规设置 | 外观主题、后台运行说明、托盘诊断、本地 HTTP 服务 |
| 翻译设置 | 默认语言、超时、历史保存/上限、失焦隐藏、默认宽高、译文字号、尺寸预设 |
| 热键设置 | 打开翻译、选中文字翻译、截图翻译 |
| 服务设置 → 翻译服务 | 添加、配置、启停、排序、测试翻译服务 |
| 服务设置 → OCR 服务 | 选择识别插件、配置参数、测试固定图片、停用或恢复默认插件 |
| 服务设置 → 插件 | 安装、查看、配置与卸载 .luminext 插件 |
| 历史记录 | 搜索、收藏、删除、载入翻译、筛选结果导出 |
| 备份设置 | 导出、导入预览、选择密钥范围、覆盖确认、恢复前备份 |
| 关于应用 | 当前版本与技术说明 |

文字识别设置集中在 OCR 服务中，不另设重复页面。关闭主窗口只隐藏；后台快捷键、托盘和已启用的 HTTP 服务继续工作。

## 翻译窗口

默认 350×420，最小 320×360。顶部是紧凑工具栏，提供置顶、关闭和任务取消。

- 手动打开时展开编辑器，提供原文、源/目标语言、交换、粘贴、复制原文、清空、翻译。
- 有效请求开始后进入阅读模式：原文缩成两行摘要，译文卡片成为主体；点击「展开原文」恢复编辑。
- 每个服务分别显示译文或错误、服务名、耗时和复制按钮；结果独立滚动。
- 默认未置顶时失焦隐藏；置顶后持续显示。隐藏取消任务，但保留原文与已完成结果。
- 无翻译服务时提供配置入口；历史管理、插件管理、偏好表单不放在翻译窗口。

设置、主题、尺寸记忆及详细交互规则见 [交互设计](ux.md)。

## 识别窗口

默认 600×700，最小 480×560。提供置顶/关闭、图片预览、选择图片、截图识字、重新识别、取消、结果编辑、复制、去换行和转翻译。

使用主窗口保存的 OCR 插件配置，重新识别时重新读取配置。关闭只取消自己的识别任务并隐藏，图片与已编辑结果保留。复制仅写入剪贴板；转翻译使用编辑后的文本。

## 截图覆盖层与入口

截图时隐藏业务窗口，框选在鼠标所在屏幕全屏显示；松开鼠标提交，右键或 Esc 取消。取消只恢复原先可见的窗口。

- 截图翻译与 HTTP `/ocr_translate`：识别完成后进入翻译窗口。
- 图片识字、截图识字与 HTTP `/ocr_recognize`：进入独立识别窗口。
- 选中文字翻译：后台读取原生选区，成功后打开翻译窗口并翻译。
- 托盘提供常用入口与明确退出操作。
