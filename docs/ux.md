# Lumin 交互与外观设计

基线：0.13.1。原生窗口，Linux 优先；设计按操作目的组织，避免把配置表单放进即时翻译流程。

## 窗口职责

| 窗口 | 核心内容 | 行为 |
| --- | --- | --- |
| 设置主窗口 | 常规外观、默认翻译参数、窗口行为/默认尺寸/字号、快捷键、服务、历史与备份 | 关闭隐藏到托盘；不会因取词或截图结果自动弹出 |
| 翻译小窗口 | 标题/显示模式/置顶/关闭；语言切换；可折叠的可编辑原文；粘贴/复制/翻译；各服务译文/耗时/错误/复制；底部状态 | 用于一次查询和阅读结果，支持置顶继续对照 |
| 识别结果窗口 | 图片预览、文字编辑、复制、重新识别、转翻译 | 保留独立任务及置顶行为，不套用翻译窗的自动隐藏 |
| 截图覆盖层 | 全屏框选与尺寸提示 | 不受业务窗口主题/失焦隐藏规则影响 |

翻译正文中保留直接影响本次任务的操作；服务配置通过空状态链接进入主窗口。未启用服务时显示配置引导；已有服务但尚未翻译时显示输入/取词提示。结果按服务顺序显示，错误留在对应卡片，不遮住其他结果。

紧凑窗口采用分区卡片：顶部小工具栏，原文摘要卡片，各服务译文卡片。手动输入时展开编辑器；有效翻译请求启动后自动进入阅读模式，原文显示两行以内的摘要，语言选择和输入动作收到编辑模式中。点击「展开原文」可继续编辑，折叠与展开不清空内容或结果；手动唤起输入窗口重新展开。译文保持用户配置的正文字号，服务名/耗时使用 11px 次要颜色，按钮 12px，避免元信息抢占阅读注意力。复制按钮与文字选择保留；不自动改写普通剪贴板。

## 失焦、隐藏与置顶

默认模式：点击翻译窗外部，失焦持续 150ms 后隐藏。期间重新获得焦点则取消隐藏；新取词请求也取消旧计时，读取期间忽略旧窗口失焦，避免源窗口的迟到失焦事件中断新一轮取词。系统焦点检测和窗口管理器行为仍需各平台真机验收。

- 隐藏只影响翻译窗口，保留原文与已完成的译文；取消当前翻译、取词或截图翻译任务，晚到结果不能重开窗口。
- 点击「置顶」同时保持显示，原生请求 AlwaysOnTop；未取消置顶时点击外部不隐藏。置顶状态在本次进程内保持，重启默认未置顶。
- 「翻译设置 → 点击其他窗口后自动隐藏（未置顶）」可关闭自动隐藏。置顶、手动关闭和 Esc 仍独立可用。
- Esc 在任务运行中先取消；无运行任务时隐藏。显式「关闭」始终隐藏，不退出进程。
- 截图隐藏/恢复窗口、已隐藏窗口和退出过程中不触发自动隐藏逻辑，避免取消截图或改变原先恢复记录。
- 配置和识别窗口不因失焦而关闭。

维护边界：bootstrap 的 OnBlur 延迟通过 Window.Update 发布，并检查焦点/可见性/截图/退出和计时代次。desktop.TranslationBlurred 只决定置顶与配置策略并复用 DismissTranslation。不要在工作线程直接写视图状态。

## 大小与阅读

| 项目 | 默认/范围 | 保存与记忆 |
| --- | --- | --- |
| 翻译窗口 | 350×420，最小 320×360 | 可拖动边缘；位置、大小和最大化状态由原生 StateKey 在正常退出时记忆 |
| 配置默认宽度 | 320–1600 逻辑像素 | 修改并保存后应用到当前窗口 |
| 配置默认高度 | 360–1200 逻辑像素 | 修改并保存后应用到当前窗口 |
| 译文字号 | 默认 16，12–24 | 只调整译文正文；保存后生效 |
| 尺寸预设 | 紧凑 350×420 / 标准 420×520 / 宽屏 520×620 | 设置草稿中选择后保存；即使默认数值相同也会重新应用，便于恢复手动改变的窗口 |

升级保留用户已保存的尺寸和 MyGo 窗口记忆；已有用户要切换小窗，在「翻译设置」点击「紧凑」并保存即可立即应用。

设置中的宽高是默认值，拖动窗口不会频繁改写用户配置。仅修改主题、字号等选项时保留手动大小；备份恢复改变默认宽高时同步应用。显示器缩放使用平台逻辑坐标，不把截图物理像素当作窗口尺寸。

译文区域独立滚动；原文编辑器固定合理高度，可折叠。服务标题可收缩，复制按钮保留空间。320×360、350×420、420×520 及旧尺寸有布局回归，大字号及长结果仍需滚动阅读。

## 深浅色

「常规设置 → 外观」：跟随系统 / 浅色 / 深色。保存后统一作用于设置、翻译、识别窗口及原生外观；跟随系统时由 MyGo 响应系统变化，无需重启。草稿未保存前不改变当前外观，放弃修改恢复已保存选项。

所有业务视图使用语义颜色，不按页面单独硬编码底色。保留 MyGo 的系统字体、尺寸与间距度量，统一改善小字号次要文字、错误文字和白色按钮文字的颜色对比。自动化验证正文/次要文字/错误文字和主要按钮在两种主题使用的背景上至少 4.5:1。禁用控件和截图画布不套用这组正文对比断言。

原生系统标题栏、托盘菜单和其他桌面部件的最终绘制由平台决定，不能用画布渲染测试证明它们已匹配。真机需检查系统深浅色即时变化及原生下拉/菜单，不因短暂焦点切换误隐藏。

## 配置兼容与实现

配置仍为 version 1，新增可选 appearance、translation_width、translation_height、translation_font_size、keep_translation_on_blur。旧配置/备份缺失时：跟随系统、350×420、16、未置顶失焦隐藏。数值 0 表示旧配置缺省，负数和超范围值拒绝。

- `desktop/appearance.go`：持久偏好编辑、语义颜色、失焦策略及保存/恢复后的显示设置应用。
- `desktop/translation_window.go`：内容层级与原文折叠，使用稳定 Key/Handle。
- `bootstrap/window_preferences.go`：原生窗口参数及快捷键差异判断。
- `bootstrap/translation_blur.go` 与 `bootstrap/run.go`：计时代次、原生焦点/主题/尺寸接口绑定；主题保存不会重新注册未变更的快捷键。

## 验收

```bash
CGO_ENABLED=0 go test ./...
go test -race ./internal/desktop ./internal/bootstrap ./internal/config
go tool mygo vet .
LUMIN_TEST_SCREENSHOTS=/tmp/lumin-ux go test ./internal/desktop -run 'TestRenderPages|TestTranslationLayoutCollapseThemesAndSmallWindow|TestCompactReadingAndEditing' -count=1
```

自动化覆盖默认/禁用自动隐藏、置顶、任务取消及内容保留、截图/重新聚焦/已隐藏/退出过滤、新取词取消旧计时、折叠/展开额外构建帧、配置保存/重启/放弃、默认预设重置和主题保存不重置手动大小、双主题对比与最小窗口布局。

真机逐项验证：

1. 未置顶取词翻译后点原应用，小窗隐藏；再次取词正常打开。置顶后切换应用仍显示，可继续复制和编辑；关闭与 Esc 正常。
2. 短暂切换焦点、语言下拉、文字选择/复制菜单不会误关；忙碌时点外部隐藏后无迟到弹窗。
3. 三个业务窗口任意显隐/置顶组合执行截图；捕获不含自身窗口，取消恢复与原流程相同。
4. 拖动大小、正常退出并重启，确认记忆；保存字号/主题不改手动大小，点击相同「标准」预设保存能恢复默认大小。
5. 系统/浅/深三模式检查三个业务窗口、下拉、服务错误、选中文字及原生标题栏；跟随系统模式切换 OS 外观实时更新。
6. Linux Wayland/KDE 与 Windows/macOS 各自验证焦点和 AlwaysOnTop；编译和 ui.Tester 不代表桌面集成验收通过。
