# 历史与收藏维护

适用 Lumin 0.8.0，入口为主窗口「历史记录」。翻译窗口不放历史管理入口。存储 schema、备份 schema 和插件协议保持不变。

## 删除

每条记录点击「删除」展开确认；点击「保留记录」取消。收藏记录额外提示会移出生词本，确认按钮为「确认删除收藏」。切换页面、修改搜索、切换收藏筛选或恢复备份会清除确认。删除不可撤销，重要数据可先用备份设置导出完整备份。

存储按 ID 删除，检查收藏状态与保存都在同一锁内完成。若确认普通记录之后记录被收藏，存储会拒绝原删除，重新载入后需确认删除收藏。保存失败不会先从界面移除记录，也不会替换旧快照。批量清理仍只删除普通历史，保留收藏。

## 导出范围

选择 JSON 或 CSV，点击「导出当前结果」。范围为当前搜索与「仅显示收藏」共同筛选后的全部记录，包括列表下方需滚动才能看到的记录。搜索匹配原文或任一译文，忽略大小写。导出在点击时固定范围和内容，在系统保存窗口中停留期间改变筛选不会改变此次导出。

导出不包含配置、API Key 字段、插件参数或 HTTP 令牌。用户原文、译文、服务显示名称和错误信息按原样导出；这些用户内容本身可能包含敏感文本。文件对话框取消不写入；写入失败保留原目标文件；成功通过临时文件同步后重命名，权限沿用私有文件策略。最多输出 64 MiB，超限请缩小搜索范围。应用数据目录中只允许直接写入 backups 子目录，禁止覆盖活动数据与插件。

## JSON

顶层字段：`format: "lumin-history"`、`version: 1`、`exported_at`、`entries`。entries 沿用 domain.Entry，包含 ID、时间、收藏状态、请求语言/原文与全部服务结果。保留 Unicode、换行、失败结果和耗时。此格式用于阅读或其他工具处理；不含恢复所需配置，不能当作 `.luminbackup` 导入。数据恢复仍使用「备份设置」。

## CSV

UTF-8、无 BOM；使用 Go encoding/csv 编码。列：

`id,created_at,favorite,source,target,text,provider_id,provider_name,translation,error,duration_ms`

每个服务结果一行，因此同一个历史 ID 可有多行；没有服务结果的记录也保留一行，结果字段为空。逗号、引号及换行由标准 CSV 引号规则保留；时间为 RFC3339Nano。适合通用 CSV 工具，不是 Anki 或欧路专有导入模板。文本值按原样保留，在表格工具中导入外部文本时应按文本字段处理。

## 代码与验证

- `desktop/history_view.go` / `history_actions.go`：列表、筛选、确认、快照和工作线程。
- `historyexport`：JSON/CSV 序列化；不依赖配置、存储或 UI。
- `storage.Delete` / `ExportHistory`：收藏保护、原子持久化与路径保护。
- 测试覆盖收藏保护、失败保留、按 ID 精确删除、多行 Unicode 往返、多服务行、空结果、筛选快照及最小窗口布局。
