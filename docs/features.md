# Lumin 功能清单与开发计划

更新：2026-11-24。初始盘点基线：宿主 0.2.0；当前宿主 0.13.1，彩云插件保持 1.0.0，PP-OCRv6 tiny 插件为 1.0.0。目标：Linux 优先的 Go + MyGo 原生翻译工具，架构保持 Windows/macOS 兼容。

本文是后续开发的任务总表。新需求先登记稳定 ID、优先级、验收条件和依赖，再实现；完成后更新本表和验证记录。具体测试证据见 [verification.md](verification.md)。不把编译成功视为桌面集成验收成功。

## 当前实现：紧凑翻译窗口（0.13.1）

0.13.1：默认 350×420，最小 320×360；有效翻译后收起输入动作，原文摘要与译文卡片分区，减弱服务名/耗时/按钮，保留译文正文阅读层级。已有窗口大小可用「紧凑」预设恢复。

UI-05：未置顶失焦隐藏、150ms 反复聚焦保护、截图/退出豁免、新取词使旧计时失效；用户可关闭自动隐藏，置顶会话内保持。UX-01：可折叠原文、语言与译文层级、可配置默认尺寸/字号和尺寸预设，保留原生拖动记忆。UI-06：系统/浅色/深色统一到三个业务窗口，文本和按钮对比度回归。原生焦点/系统主题切换仍待实机，设计与验收见 [ux.md](ux.md)。

## 已实现：选中文字快捷翻译（0.12.1 / SEL-01，用户确认 VS Code 可用）

快捷键和托盘读取当前应用选区，成功后弹出小窗自动翻译，无需复制；不读写普通剪贴板，不回退历史内容。Linux Wayland 原生 PRIMARY（不可用时尝试 AT-SPI）、X11 AT-SPI、Windows UIA、macOS AX 提供平台实现；应用需提供所用平台的选区接口。移除剪贴板监听，编辑器保留显式复制/粘贴。旧快捷键及禁用状态兼容保留。自动化不代表真实应用覆盖，验收见 [取词说明](selection-translation.md)。

## 已实现：截图延迟与快捷键显示优化（0.11.1）

PERF-01：后台无可见业务窗口时跳过 200ms 合成器等待；位图准备离开 UI 线程，临时 PNG 使用无损快速压缩。增加可选阶段计时，实测端到端耗时仍需用户桌面复验。UI-04：热键显示解析为当前平台的 Ctrl / Cmd 并增加分隔空格，编辑、保存、禁用、页面切换及放弃修改有界面回归。

## 已实现：运行时工具独立化（0.11.0 / DEP-01）

移除历史 Tesseract 示例；Linux 截图只使用门户，Windows 改用进程内 GDI，macOS 14+ 改用 ScreenCaptureKit。Windows 插件清理改用 Job Object；插件 PATH 限于自身目录，官方 OCR 自带模型和运行库。旧示例引用可迁移到随包引擎。Linux 真实 OCR 和回归通过，Windows/macOS 原生截图仍待真机验证。基础系统服务和权限边界见 [运行依赖](runtime-dependencies.md)。

## 已完成：全屏框选交互（0.10.0 / CAP-06）

采用鼠标释放提交，移除占用画面的工具栏；画布铺满窗口，左键拖拽松开即识别，右键/Esc 取消。无边框覆盖层在目标显示器定位并进入全屏后显示；尺寸/操作提示只绘制在画面上。极小或取消的拖动不提交，可重选；结束事件只触发一次。多屏和混合 DPI 仍需实机验证。

## 已实现：OCR 独立化（0.9.0）

Lumin 按独立产品维护，以用户体验和稳定性为目标。OCR-04：移除宿主系统 Tesseract 回退，Linux/Windows x64 发布包随附默认离线插件；首次启动安装/配置，保留已有引擎与主动停用。OCR-02：OCR 服务中统一展示引擎、选择/参数编辑/固定图片测试，取消、过期结果及界面隔离。后续优先真实识别体验、性能和发布稳定性。

## 已实现：历史单条删除与导出（0.8.0 / DATA-03）

按 ID 确认删除，收藏单独提示并由存储层保护；导出当前搜索/收藏过滤结果，支持 CSV/JSON，保留 Unicode、多行文本和多服务译文，仅导出历史字段。文件提交失败保留原文件，禁止覆盖应用数据目录。

## 已完成：PP-OCRv6 tiny 离线 OCR 插件（1.0.0）

PLG-06：新增独立 `.luminext` OCR 插件，随包提供 PP-OCRv6 tiny 检测/识别模型、字典和 CPU 运行库。Linux amd64 已通过宿主插件管理器安装、真实子进程识别和取消/参数错误回归；Windows amd64 完成交叉构建与包内容检查。模型运行完全离线，但当前只支持 PP-OCRv6 tiny 管线，不是通用 ONNX Runtime，也没有 macOS/ARM 包或 180° 方向分类。详细限制见 [插件说明](../plugins/ppocrv6-tiny/README.md)。

## 本轮完成：配置与历史备份恢复（0.7.0）

DATA-02：主窗口备份页；64 MiB / 50000 条历史上限；导入只读校验与预览，勾选确认后覆盖；覆盖前自动保留完整恢复备份；默认移除已知凭据，完整明文导出显式选择。数据存储迁移为 state.json，失败不替换现有快照。详细契约见 backups.md。DATA-03 已在 0.8.0 实现。

## 已完成：独立 OCR 结果窗口（0.6.0）

识别窗口边界：图片预览、编辑、复制、去换行、重新识别、转翻译；识别任务与翻译任务独立取消。全屏截图隐藏三个业务窗口；取消不打开隐藏窗口，迟到结果不能重新弹窗。回归与平台限制见 verification.md。随后已在 0.7.0 完成 DATA-02。

## 状态与优先级

- **已实现**：已有可调用代码和相应自动化验证；不代表全部平台真机验收完成。
- **待实机**：代码已实现，仍缺指定桌面、权限或真实服务验证。
- **待开发 / 进行中 / 已完成**：后续任务的进度；“已完成”须满足该行验收标准，并注明平台限制。
- **P0**：影响当前基本使用、排错或数据可靠性；**P1**：高频日常功能；**P2**：生态和发布完善。
- 优先级是开发顺序，不是承诺发布日期。平台限制可使某项验收等待，同时推进不依赖该限制的任务。

## 推荐推进顺序

1. OCR-02 / OCR-04 已实现，继续验收 Linux/Windows 默认离线识别与多屏快捷键体验。
2. 按实测瓶颈优化 OCR 冷启动、内存和小字识别；常驻进程缓存需先升级协议并明确取消与释放生命周期，当前仍是一请求一进程。
3. 翻译体验 TR-04 / TR-05 / TR-06，插件配置与版本管理。

不自动扩大范围：新的收费服务、云同步账号、发布渠道或平台签名身份须有实际需求和配置；相关条目保持待开发，不创建无效占位按钮。

## 每项任务的维护规则

1. 开发前选定 ID，写明这次要达成的行为与不确定平台条件，状态改为进行中。
2. 修改放在对应职责包；系统能力不进入视图，插件逻辑不进入宿主业务层。
3. 涉及并发、持久化、协议或 UI identity 时补行为测试；网络测试默认不调用真实收费接口。
4. 通过针对性验证后更新状态、证据路径与变更记录。新增数据格式要明确旧版本处理方式。
5. 记录当前剩余限制；“待实机”必须由实际运行证据关闭，不随版本号自动关闭。
6. 用户变更优先级时更新本表，保留 ID；拆分任务用后缀，避免历史引用失效。
