# Lumin 功能清单与开发计划

更新：2026-11-23。初始盘点基线：宿主 0.2.0；当前宿主 0.4.0，彩云插件保持 1.0.0。目标：Linux 优先的 Go + MyGo 原生翻译工具，架构保持 Windows/macOS 兼容。

本文是后续开发的任务总表。新需求先登记稳定 ID、优先级、验收条件和依赖，再实现；完成后更新本表和验证记录。Pot 对照细节见 [migration.md](migration.md)，具体测试证据见 [verification.md](verification.md)。不把编译成功视为桌面集成验收成功。

## 状态与优先级

- **已实现**：已有可调用代码和相应自动化验证；不代表全部平台真机验收完成。
- **待实机**：代码已实现，仍缺指定桌面、权限或真实服务验证。
- **待开发 / 进行中 / 已完成**：后续任务的进度；“已完成”须满足该行验收标准，并注明平台限制。
- **P0**：影响当前基本使用、排错或数据可靠性；**P1**：高频日常功能；**P2**：生态和发布完善。
- 优先级是开发顺序，不是承诺发布日期。平台限制可使某项验收等待，同时推进不依赖该限制的任务。

## 推荐推进顺序

1. SVC-02 / SVC-03 / CFG-02 已在 0.3.0 完成；本次优先实现 OS-02a / UI-02 / CAP-04，QA-01 / QA-02 记录用户已确认链路及剩余桌面验收项。
2. 数据可靠性 DATA-02，再做 DATA-03、DATA-04。
3. 高频体验 TR-04 / TR-05、SEL-01、CAP-02、OCR-02；结合实机结果确定先后。
4. 按实际使用需求扩展服务与插件，最后完善发布、国际化与更新。

不自动扩大范围：新的收费服务、云同步账号、发布渠道或平台签名身份须有实际需求和配置；相关条目保持待开发，不创建无效占位按钮。

## 每项任务的维护规则

1. 开发前选定 ID，写明这次要达成的行为与不确定平台条件，状态改为进行中。
2. 修改放在对应职责包；系统能力不进入视图，插件逻辑不进入宿主业务层。
3. 涉及并发、持久化、协议或 UI identity 时补行为测试；网络测试默认不调用真实收费接口。
4. 通过针对性验证后更新状态、证据路径与变更记录。新增数据格式要明确旧版本处理方式。
5. 记录当前剩余限制；“待实机”必须由实际运行证据关闭，不随版本号自动关闭。
6. 用户变更优先级时更新本表，保留 ID；拆分任务用后缀，避免历史引用失效。
