# 截图框选与 OCR

## 使用

点击「截图识字」或「截图翻译」，也可从托盘启动。默认截图翻译快捷键为 `Ctrl+Alt+S`，macOS 为 `Cmd+Alt+S`。从 0.1.0 升级的已有配置若缺少 `screenshot_shortcut`，快捷键保持禁用，需在设置中填写并保存。

当前可见的配置窗口和翻译小窗口暂时隐藏，应用获取一张屏幕快照，随后打开原生全屏框选窗口。拖拽选中区域，按 Enter 或点击「识别选区」；Esc 或「取消截图」放弃。可重新拖拽修改选区，支持从任意方向拖动。选区至少 2×2 原图像素。

快照按比例显示，可能出现留白。多显示器快照会整体缩放到框选窗口，**不是每台显示器各开一个覆盖层**。框选位置按归一化坐标映射回原图像素，裁剪使用原始分辨率；界面中的 px 表示实际裁剪尺寸。当前不支持选区拖动手柄、滚轮放大或跨多个窗口连续框选。

确认或取消后，只恢复截图前可见的窗口（不抢焦点），使用已保存的 OCR 引擎。识别成功后打开翻译小窗口；从后台发起截图不会打开设置。取消截图保持原来的可见状态；获取或识别错误会在小窗口显示。截图识字将文字填入编辑器；截图翻译随后调用已启用翻译服务。没有服务时在小窗口提示，点击「配置翻译服务」才打开设置。屏幕图片不会作为翻译请求发送给普通文本翻译服务；若选择云端 OCR 插件，它可按自身实现上传选区图片。

当前一次只运行一个识别/翻译任务。已有任务忙碌时，新的截图动作忽略；可以先取消任务再截图。整个识别流程（包括系统权限与选区等待）上限 90 秒，超时会关闭框选窗口并按原可见状态恢复窗口。

## 平台获取方式

| 平台 | 实现 | 验证范围 |
| --- | --- | --- |
| Linux Wayland / X11 | XDG Desktop Portal Screenshot，通过会话 D-Bus 请求；`interactive=false` 后由 Lumin 框选 | 用户已确认当前环境截图 OCR 可用；具体门户后端、拒绝授权和多屏待验收 |
| Linux 门户缺失 | Wayland 尝试 `grim`，X11 尝试 `maim` | 仅门户不存在时回退，工具需用户安装；桌面必须支持 |
| macOS | 系统 `/usr/sbin/screencapture -x -m -t png` | 主显示器快照，交叉编译通过；录屏授权待真机验证 |
| Windows | PowerShell + Windows Forms/Drawing 读取虚拟桌面，设置 DPI awareness | 多屏合并图片，交叉编译通过；混合 DPI 待真机验证 |

Linux 需启动 `xdg-desktop-portal` 和匹配桌面的后端，且后端提供 Screenshot 接口。桌面可能弹出授权窗口，某些后端还会先让用户选择屏幕/区域；Lumin 对后端返回的图片继续框选。`interactive=false` 不代表绕过授权。门户拒绝、用户取消或运行出错时不会尝试其他工具绕过；只有接口或服务不存在才尝试备用工具。`grim` 常见于支持其协议的 Wayland 合成器，不保证所有 Wayland 桌面可用。

全局快捷键的授权由 MyGo / 桌面门户处理，与截图权限是两条独立链路。快捷键不可用时可从界面或托盘截图。

macOS 可能需要给实际运行程序或终端授予屏幕录制权限。当前仅主显示器，其他显示器支持须在后续系统适配中扩展。

## 图片生命周期

系统快照解码前检查大小和像素数，上限 64 MiB / 6400 万像素。框选结果编码为权限 `0600` 的临时 PNG，交给 OCR 后清理，失败和取消也清理。Windows/macOS/备用工具的完整截图暂存目录会清理。

门户返回的原图由门户/桌面管理；应用不会删除任意门户返回路径，因此不能保证门户后端不保留截图。应用生成的选区临时文件不进入历史；历史只保存文字与译文。OCR 入口文件上限为 20 MiB，大面积高熵选区可能超限，提示后缩小选区即可。

## 实现边界

- `internal/capture`：各系统抓屏、解码限制、坐标换算、原图裁剪与临时文件。
- `internal/desktop/selection.go`：框选状态与原生画布。只保存位图、数据与 `ui.Handle`，不跨帧保存元素。
- `internal/bootstrap/capture.go`：与 `windows.go` 配合隐藏/恢复两个窗口、创建与关闭框选窗口；所有窗口操作通过 `mygo.RunOnMain`。
- `internal/desktop/app.go`：识别与翻译衔接，context 取消、generation 校验。
- `desktop.Ports.CaptureArea`：测试可替换为固定图片，不需要真实桌面。

截图和 OCR 在后台执行。保存配置、输入新文本、取消或关闭翻译窗口使旧结果失效；晚到的识别结果不会覆盖新输入。

## 自动化与真机验收

```bash
go test ./internal/capture ./internal/desktop
LUMIN_TEST_SCREENSHOTS=/tmp/lumin-screenshots \
  go test ./internal/desktop -run 'TestRenderPages|TestSelectionDragResizeAndCancel' -count=1
```

自动化覆盖原图像素、反向拖动、边界裁剪、窗口缩放、指针取消、Enter/Esc、异步结果隔离、临时文件清理和截图到翻译链路。测试使用固定图片，不能证明系统授权或屏幕获取成功。

真机需分别检查：

1. 从按钮、托盘、快捷键启动，两个应用窗口都不会出现在快照中；分别测试设置可见、翻译可见、两个可见和全部隐藏。取消后仅恢复之前可见窗口，后台截图不唤起设置。
2. 门户授权允许、拒绝、取消；拒绝后不回退工具，90 秒超时后可重新操作。
3. 框选四个方向、小区域、整图、边界与留白；多屏横排/竖排、负坐标、不同缩放比例。
4. OCR 设置 `eng` 识别已知英文，再安装 `chi_sim` 验证中英混排；切换 OCR 插件确认截图与图片导入都生效。
5. 拖动期间 Esc、关闭框选窗口、任务超时；不存在遗留覆盖窗口或临时选区图片。
6. 截图翻译后检查编辑器、译文与历史；无翻译服务时给出配置引导。
7. 外部 `POST /ocr_recognize`、`POST /ocr_translate` 带 Bearer 令牌触发相同交互，不返回 OCR 文本。仍需用户授权与框选。

门户协议参考：[XDG Screenshot interface](https://flatpak.github.io/xdg-desktop-portal/docs/doc-org.freedesktop.portal.Screenshot.html)。
