# Pot 3.0.7 迁移清单

迁移依据是本仓库的 `pot-desktop-3.0.7/README.md`、`src/services`、`src/window` 和 `src-tauri/src`。Lumin 0.1.0 采用新的 Go 原生实现，不加载旧前端或 Rust 后端。

| 原功能 | Lumin 0.1.0 状态 | 说明 |
| --- | --- | --- |
| 输入翻译 | 已实现 | 原生多行编辑器、语言选择、复制、快捷键 |
| 多接口并行翻译 | 已实现 | 最多并发 4 个，逐服务完成显示，独立错误 |
| OpenAI 类接口 | 已实现协议适配 | 完整 Chat Completions URL、用户指定模型；不含 Azure 特殊认证 |
| Ollama | 已实现协议适配 | 本地 `/api/chat`，模型需预先安装 |
| DeepL | 已实现官方 API | 用户配置账号接口和密钥，不迁移网页逆向免费接口 |
| LibreTranslate | 新增协议适配 | 自建或已有兼容服务 |
| 百度、腾讯、Google、Bing、Gemini 等 | 待迁移 | 独立协议及语言映射；兼容 Chat Completions 的服务可先用现有适配 |
| 剪贴板翻译 | 已实现 | 按钮、全局快捷键和托盘入口 |
| 剪贴板监听 | 已实现，依赖桌面能力 | 用户主动开启，默认关闭，避免复制译文形成循环 |
| 划词翻译 | 待迁移 | 当前需先复制选中文本；没有自动读取其他应用选区 |
| 全局快捷键 | 已接入 MyGo | Linux Wayland 需桌面门户支持和授权 |
| 系统托盘 | 已接入 MyGo | 不支持时给出提示；当前关闭窗口即退出 |
| 图片 OCR | 已实现 Tesseract 适配 | 原生文件选择器导入图片、识字、编辑后翻译 |
| 截图框选及截图翻译 | 待迁移 | 后续使用桌面门户/系统能力，并验证权限流程 |
| Windows OCR / Apple Vision | 待迁移 | 保留 Recognizer 接口；当前各平台均可安装 Tesseract |
| 历史记录 | 已实现 | 搜索、载入、普通历史上限、原子保存 |
| 本地生词本 | 已实现 | 从历史收藏、取消收藏，清理普通历史时保留 |
| Anki、欧路等外部生词本 | 待迁移 | 后续独立 collection 适配 |
| 外部 HTTP 调用 | 部分兼容 | 输入、翻译、设置；需 Bearer 令牌，返回 202 |
| 流式 LLM 译文 | 待迁移 | 当前单服务一次性响应，服务之间并行 |
| 语音合成 | 待迁移 | 后续独立 speech 能力 |
| `.potext` 插件 | 不兼容，待设计 | 不能直接加载旧 JS/native 插件；先明确隔离和权限边界 |
| 旧数据导入、备份同步 | 待迁移 | 当前仅新版本本地文件备份 |
| 多语言 UI、自动更新、开机启动 | 待迁移 | 当前中文 UI、手动升级 |

## 建议后续顺序

1. 在 Linux 目标桌面完成托盘、中文输入法、剪贴板和快捷键门户真机验证。
2. 增加桌面截图入口、框选与选区文本获取，形成更接近 Pot 的日常交互。
3. 按实际使用频率迁移其他翻译/OCR 服务，加流式返回和模型参数。
4. 实现旧配置和历史导入、Anki 导出、语音合成。
5. 明确新插件协议，再补齐自动更新、国际化和三平台发布验证。

这些项目是未完成工作，不是占位按钮已经实现的功能。当前 UI 只展示已有操作。
